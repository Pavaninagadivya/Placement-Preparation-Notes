# Percentages

## 1. Basic Percentage

Percentage means "per hundred".

### Formula

Percentage = (Part / Total) × 100

### Example

If 25 students out of 50 students passed:

Percentage = (25 / 50) × 100
           = 50%

---

## 2. Converting Percentage to Decimal

To convert a percentage into a decimal, **divide by 100**.

### Formula

Decimal = Percentage / 100

### Examples

50% = 50 / 100 = 0.5

25% = 25 / 100 = 0.25

12.5% = 12.5 / 100 = 0.125

---

## 3. Converting Decimal to Percentage

To convert a decimal into a percentage, **multiply by 100**.

### Formula

Percentage = Decimal × 100

### Examples

0.5 = 0.5 × 100 = 50%

0.25 = 0.25 × 100 = 25%

0.125 = 0.125 × 100 = 12.5%

---

## 4. Percentage Increase

Percentage increase tells us how much a value has increased compared to its original value.

### Formula

Percentage Increase = (Increase / Original Value) × 100

Where:

Increase = New Value - Original Value

### Quick Trick

If a value increases by x%:

New Value = Original Value × (1 + x/100)

### Example

Increase 500 by 20%.

New Value = 500 × (1 + 20/100)

           = 500 × 1.2

           = 600

---

## 5. Percentage Decrease

Percentage decrease tells us how much a value has decreased compared to its original value.

### Formula

Percentage Decrease = (Decrease / Original Value) × 100

Where:

Decrease = Original Value - New Value

### Quick Trick

If a value decreases by x%:

New Value = Original Value × (1 - x/100)

### Example

Decrease 500 by 20%.

New Value = 500 × (1 - 20/100)

           = 500 × 0.8

           = 400

---

## 6. Profit Percentage

Profit occurs when the Selling Price (SP) is greater than the Cost Price (CP).

### Formula

Profit = SP - CP

Profit Percentage = (Profit / CP) × 100

### Example

Cost Price = ₹500

Selling Price = ₹600

Profit = 600 - 500 = ₹100

Profit Percentage = (100 / 500) × 100

                 = 20%

---

## 7. Successive Percentage Change

When a value changes more than once, the changes are called successive percentage changes.

### Formula

For two successive changes of x% and y%:

Net Change = x + y + (xy/100)

For a decrease, use a negative value.

### Example 1: Two Increases

A value increases by 20% and then by 10%.

Net Change = 20 + 10 + (20 × 10)/100

           = 30 + 2

           = 32% increase

### Example 2: Increase and Decrease

A value increases by 20% and then decreases by 10%.

Net Change = 20 - 10 - (20 × 10)/100

           = 10 - 2

           = 8% increase

---

## 8. Population Growth

Population growth is calculated using percentage increase over a period of time.

### Formula

Final Population = P × (1 + r/100)^n

Where:

- P = Initial Population
- r = Growth Rate
- n = Number of years

### Example

Initial population = 10,000

Growth rate = 10%

Time = 2 years

Final Population = 10000 × (1 + 10/100)^2

                 = 10000 × (1.1)^2

                 = 12,100

---

## 9. Population Decrease

If the population decreases by a certain percentage every year:

### Formula

Final Population = P × (1 - r/100)^n

Where:

- P = Initial Population
- r = Decrease Rate
- n = Number of years

### Example

Initial population = 10,000

Decrease rate = 10%

Time = 2 years

Final Population = 10000 × (1 - 10/100)^2

                 = 10000 × (0.9)^2

                 = 8,100

---

## 10. Important Percentage Tricks

### Trick 1

x% of y = y% of x

Example:

20% of 50 = 50% of 20 = 10

### Trick 2

Common Percentage to Fraction

| Percentage | Fraction |
|------------|----------|
| 10% | 1/10 |
| 20% | 1/5 |
| 25% | 1/4 |
| 50% | 1/2 |
| 75% | 3/4 |
| 12.5% | 1/8 |

### Trick 3

Common Fraction to Percentage

1/2 = 50%

1/4 = 25%

1/5 = 20%

1/8 = 12.5%

1/10 = 10%

---

## Key Points

- Percentage means per hundred.
- To convert percentage to decimal, divide by 100.
- To convert decimal to percentage, multiply by 100.
- Percentage increase and decrease are calculated using the original value.
- Profit percentage is always calculated on Cost Price.
- Successive percentage changes should not simply be added.
- Population growth and decrease use compound percentage formulas.
